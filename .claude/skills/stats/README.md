# ベンチマーク統計ガイド

ベンチマークレポートに登場する SD (標準偏差) や Cohen's d (効果量) などの
統計指標について、専門知識がなくても理解できるよう解説する。

## 1. SD (標準偏差) とは

SD (Standard Deviation、標準偏差) は計測値のばらつきの大きさを表す指標。

平均からの「ずれ」を二乗して平均し、平方根をとったもの。
計測値が平均の周りにどの程度散らばっているかを 1 つの数値で表す。

### 計算方法

不偏標準偏差 (サンプル SD) の式:
  SD = sqrt( Σ(x_i - x̄)² / (n - 1) )

計算例 (Server Push, gpt-oss-20b tg, B条件 15回):
  計測値 = [7.78, 7.76, 7.77, 7.75, 7.76, 7.78, 7.77, 7.76, 7.75, 7.76, 7.77, 7.76, 7.75, 7.76, 7.77]
  平均 x̄ = 7.763
  SD = 0.015
  → レポートで「7.763 ± 0.015」と記載

### SD と SD_diff の違い

- **SD**: 単一条件の計測値のばらつき (レポートの「平均 ± SD」の部分)
- **SD_diff**: ペア差分のばらつき (Cohen's d の分母)

SD が小さい = 計測が安定している。レポートの「平均 ± SD」を見れば
その条件の計測精度がすぐ分かる。

SD_diff が小さい = 条件間の差が安定している。
全ペアで同じ方向・同じ大きさの差が出ている状態。

### SD の大きさの目安

| SD / 平均 (変動係数) | 解釈 |
|:---:|---|
| < 0.5% | 非常に安定 (例: gpt-oss-20b tg, SD ≈ 0.015) |
| 0.5% - 2% | 通常のばらつき |
| > 2% | ばらつきが大きい (例: GLM-4.7 tg, GPU間同期の変動) |

## 2. 効果量とは

効果量は「差がどれだけ大きいか」を標準化した指標である。

p 値が「差があるかどうか」を判定するのに対し、効果量は「その差がどの程度の大きさか」を示す。
たとえば、ある最適化で推論速度が +1.45% 改善したとき:

- **p 値** → 「この差は偶然ではない」(統計的有意性)
- **効果量** → 「計測ばらつきに対して、この差は非常に大きい」(実質的な意味)

両方を合わせて初めて「この最適化は意味がある」と結論できる。

## 3. Cohen's d の計算方法

このプロジェクトでは ABAB Paired Design (対応ありデザイン) を使うため、
Cohen's d は以下の式で計算する:

```
d = mean_diff / SD_diff
```

- **mean_diff**: A/B ペアごとの差分の平均
- **SD_diff**: A/B ペアごとの差分の標準偏差

**計算例** (Deferred Copy, gpt-oss-20b, pp):

8 ペアの差分 = [+2.61, +4.83, +12.27, +5.20, +3.65, +3.76, +13.97, +4.23]
- mean_diff = +6.3 t/s
- SD_diff = 4.1 t/s
- d = 6.3 / 4.1 = **1.54**

d が大きいほど、ばらつきに比べて差が大きい (= 信号がノイズに対して強い) ことを意味する。

## 4. 解釈の目安

### Cohen の基準

| 効果量 (|d|) | 解釈 | 意味 |
|:---:|:---:|---|
| < 0.2 | 無視できる | 計測ばらつきの範囲内。実質的な差はない |
| 0.2 - 0.5 | 小さい | 差はあるが、ばらつきに対して小さい |
| 0.5 - 0.8 | 中程度 | 差が明確に見え始める |
| ≥ 0.8 | 大きい | 差がばらつきを大きく上回る |

### このプロジェクトでの判定基準

SKILL.md セクション 5 で定めた判定基準:

- **有効**: p < 0.05 **かつ** 効果 > 0.5% (両方必要)
- **効果なし**: p ≥ 0.05 **または** 効果 < 0.5%

効果量 (d) は直接の判定基準には含まれないが、結果の信頼度を補強する指標として
レポートに必ず記載する。d が大きいほど、結果の再現性が高いと期待できる。

## 5. なぜ p 値だけでは不十分か

### 問題 1: サンプル数依存性

p 値はサンプル数が増えるほど小さくなる。十分なサンプル数があれば、
実用上意味のない微小な差でも「統計的に有意」(p < 0.05) になる。

例: +0.03% の差でも n=100 なら有意になりうるが、実用的には無意味。

→ そのため判定基準では p 値に加えて **効果 > 0.5%** を要求している。

### 問題 2: サンプル数が少ないと検出できない

逆に、サンプル数が少ないと、実際に大きな差があっても p ≥ 0.05 になることがある。
「p が有意でない = 差がない」とは言えない。

例: Hugepage Staging (d = 0.44) は n=15 で p = 0.110 だったが、
n=30 まで増やせば有意になった可能性がある。

### 問題 3: 効果の大きさが分からない

p = 0.001 と p = 0.00001 の違いは、効果が大きいことを意味しない。
どちらも「偶然ではない」という同じ結論になる。

効果の大きさを知るには Cohen's d や差分の % を見る必要がある。

## 6. このプロジェクトでの実例

過去のベンチマークレポートから代表的な事例を示す。

### 大きな効果が検出された例

| 最適化 | モデル | 指標 | d | p 値 | 効果 | 判定 |
|-------|-------|------|:---:|:---:|:---:|:---:|
| Deferred Copy | gpt-oss-20b | tg | 2.17 | 0.004 | +1.6% | 有効 |
| Deferred Copy | gpt-oss-20b (再検証) | tg | 5.89 | 1.8×10⁻¹² | +1.45% | 有効 |
| Server Push | gpt-oss-20b | tg | 4.30 | 1.3×10⁻¹⁰ | +1.85% | 有効 |

d > 1.0 の場合、8-12 ペアでも十分に検出できる。15/15 ペアで正の効果など、
一貫性も高い。

### 中程度の効果が検出された例

| 最適化 | モデル | 指標 | d | p 値 | 効果 | 判定 |
|-------|-------|------|:---:|:---:|:---:|:---:|
| Deferred Copy | GLM-4.7 | tg | 0.58 | 0.009 | +5.9% | 有効 |

d ≈ 0.5 では 20 ペア必要だった。GLM-4.7 は分散が大きいため、
ペア差分の SD が大きく d が小さくなる。それでも % としては +5.9% と大きい。

> **注意**: d が小さい ≠ 効果が小さい。分散が大きいモデルでは、
> 同じ % 改善でも d は小さくなる。% と d は補完的に見ること。

### 効果が検出されなかった例

| 最適化 | モデル | 指標 | d | p 値 | 効果 | 判定 |
|-------|-------|------|:---:|:---:|:---:|:---:|
| Hugepage Staging | gpt-oss-20b | tg | 0.44 | 0.110 | +0.29% | 効果なし |
| Hugepage Staging | gpt-oss-20b | pp | 0.26 | 0.340 | +0.03% | 効果なし |
| Deferred Copy | gpt-oss-20b (再検証) | pp | -0.18 | — | +0.14% | 効果なし |

d < 0.5 かつ n=15 では有意にならなかった。Hugepage Staging は tg で d = 0.44 と
一定の効果量を示すものの、p = 0.11 で有意水準に達せず、効果 +0.29% も判定基準の
0.5% 未満であるため「効果なし」と判定された。

### 負の効果 (性能低下) の例

| 最適化 | モデル | 指標 | d | p 値 | 効果 | 判定 |
|-------|-------|------|:---:|:---:|:---:|:---:|
| Shared PD + Per-device | gpt-oss-20b | pp | -5.31 | <0.001 | -2.3% | 有害 |
| Hugepage + GDR | gpt-oss-20b | pp | -0.81 | <0.05 | -0.6% | 有害 |

d が負の場合は性能低下を意味する。|d| > 0.8 かつ p < 0.05 であれば、
最適化が逆効果であることを統計的に示している。
