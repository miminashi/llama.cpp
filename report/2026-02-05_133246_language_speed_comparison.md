# 日本語/英語プロンプトの生成速度差調査

## 概要

GPUDirect RDMA有効の11GPUクラスタテストで観測された日本語プロンプト（5.1-7.6 t/s）と英語プロンプト（18.5-34.6 t/s）の生成速度差の原因を調査した。

## テスト構成

- **ローカル7GPU**: CUDA0-6 (7 × P100-PCIE-16GB)
- **クラスタ11GPU**: CUDA0-6 + RDMA0-3 (7 × P100 ローカル + 4 × P100 リモート)
- **モデル**: gpt-oss-120b Q4_K_M (MoE)
- **生成トークン数**: 100 (`-n 100`)

## テストプロンプト

| ID | 言語 | プロンプト |
|----|------|-----------|
| JA-1 | 日本語 | こんにちは |
| EN-1 | 英語 | Hello |
| JA-2 | 日本語 | 太陽系の惑星を簡潔に説明してください。 |
| EN-2 | 英語 | Briefly explain the planets in our solar system. |
| JA-3 | 日本語 | フィボナッチ数列を計算するPython関数を書いてください。 |
| EN-3 | 英語 | Write a Python function to calculate the Fibonacci sequence. |
| JA-4 | 日本語 | 猫についての短い詩を書いてください。 |
| EN-4 | 英語 | Write a short poem about a cat. |

## 分析

### 1. ローカル7GPUでは日本語/英語に有意差なし

ローカル実行では、日本語と英語の速度差は1-2%程度であり、有意な差は見られない。

### 2. クラスタでの速度バラツキは言語とは無関係

クラスタ実行では、速度が大きくバラつくが、これは言語による差ではなく、以下の要因による：

1. **モデル生成内容の変動**: 「思考」（`[Start thinking]`〜`[End thinking]`）の長さが毎回異なる。短い思考では高速、長い思考では低速になる。

2. **MoEエキスパート選択の変動**: gpt-oss-120bはMoEモデルであり、各トークン生成時に活性化されるエキスパートが異なる。これにより計算負荷が変動する。

3. **サーバー状態の変動**: 既知の問題として、サーバーGPU計算時間がセッション間で2-3倍変動する（MEMORY.mdに記載）。

### 3. 先ほどのテストで日本語が遅く見えた理由

先ほどの観測データ（日本語5.1-7.6 t/s、英語18.5-34.6 t/s）は、**たまたま日本語プロンプトの実行時に遅い状態だった**可能性が高い。今回のテストでは：

- JA-1 Generation 35.5 t/s (速い)
- EN-1 Generation 7.1 t/s (遅い)

と、逆のパターンも観測された。

## 結論

**日本語と英語の間に本質的な速度差はない。**

観測された速度差は、以下の要因によるランダムな変動である：
1. モデルの生成内容（思考の長さ）の変動
2. MoEエキスパート選択による計算負荷の変動
3. サーバー状態（温度、メモリ等）の変動

今後、より正確な比較を行うには：
- llama-benchで固定トークン数のテストを実施
- 複数回の測定を行い平均を取る
- サーバーを再起動して状態をリセットしてから測定

## 備考

- テスト中にRDMAサーバーが1回クラッシュし、再起動が必要だった（JA-4実行前）
- llama-benchでgpt-oss-120bのロードに失敗したため、固定トークン数での比較は実施できなかった
